ASCII Card Studio - v1.0

Visually design the Kali-styled README card, then copy the config straight back into profile.svg's generator script.

Quick guide
  1. Configure each panel below — Identity, GitHub Stats, Profile Fields, Terminal Prompt, Color Palette, and ASCII & Animations. The preview on the right (or above, on narrower screens) updates in real-time as you type.
  2. Once you’re satisfied, open the Python snippet tab below the preview and click Copy snippet.
  3. Paste the copied content into the top of your scripts/generate_card.py file, overwriting the existing PROFILE_FIELDS, PROMPT_COMMANDS, and the color/size constants.
  4. Commit and push your changes. The existing GitHub Actions workflow will automatically re-render assets/profile.svg — no further changes to the workflow are required.
All processes on this page run entirely within your own browser—nothing is uploaded to any server. You can save your progress at any time via the Save/load config tab below the preview.
