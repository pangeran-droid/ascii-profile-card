ASCII Card Studio — v1.2

Visually design the Kali-styled README card, then copy the config straight back into profile.svg's generator script.

Quick guide
  1. Configure each panel below — Identity, GitHub Stats, Profile Fields, Terminal Prompt, Color Palette, and ASCII & Animations. The preview on the right (or above, on narrower screens) updates in real-time as you type.
  2. Add art directly in assets/art-collection.js: write @@@ Name, paste the ASCII, then click Next art to browse the collection.
  3. Already running the Python version? Each of the Profile Fields and Terminal Prompt panels has a paste-to-import box, so you don't have to retype anything.
  4. Once you're satisfied, open the Python snippet tab below the preview and click Copy snippet, then paste it into the top of scripts/generate_card.py, overwriting the matching constants.
  5. Open the README embed tab for a ready-to-paste <img> snippet for your README.md.
  6. Commit and push. The existing GitHub Actions workflow re-renders assets/profile.svg automatically — no workflow changes needed.
Everything on this page runs in your own browser — nothing is uploaded anywhere. Save your progress any time from the Save/load config tab below the preview.
